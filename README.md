# GhostGather

GhostGather is a simple OSINT tool for gathering information about IP addresses, domains, emails, phone numbers, and usernames.

## Features

- IP geolocation and port scanning
- Domain WHOIS and DNS records
- Email verification and leak search
- Phone number lookup
- Username search across platforms

## Installation
git clone https://github.com/pnikitos327-sys/GhostGather.git
cd GhostGather
pip install -r requirements.txt


## Usage
python -m ghostgather


Enter any target like:
- 8.8.8.8
- google.com
- email@example.com
